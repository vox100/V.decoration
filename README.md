V.decorations - Android APK project

هذا مشروع أندرويد يغلّف نسخة HTML داخل WebView.
لإنشاء APK باستخدام GitHub Actions:
1) أنشئ مستودع GitHub جديد وارفع كل محتويات هذا المجلد إليه.
2) افتح تبويب Actions في المستودع.
3) اختر Build V.decorations APK ثم Run workflow.
4) بعد انتهاء البناء افتح صفحة التشغيل وانزل إلى Artifacts.
5) نزّل V-decorations-debug-apk وفك ضغطه لتحصل على app-debug.apk.

ملاحظات:
- هذا APK تجريبي Debug للتثبيت والاختبار والمشاركة المباشرة، وليس إصدار متجر Play موقّعًا بمفتاح نشر.
- صفحة HTML تعتمد على Tailwind وGoogle Fonts وFont Awesome عبر الإنترنت؛ لذلك يلزم اتصال إنترنت لبعض التنسيقات والخطوط والأيقونات.
- اسم التطبيق: V.decorations
